# 复查一批学校实体的已登记别名

你拿到一批学校实体(每校带 entityId + 当前已登记的别名清单,见批次给定的清单文件)。逐校复查这些写法,把误挂的撤掉。这些写法里有一部分是早期用过宽的"挂了校名就归本校"标准登进去的(独立学院、成人 / 自考 / 继续教育等被错当成本部统招学历),现在按学历归属重新核一遍,确属误挂的用 `alias remove` 撤回。这是审查撤回任务,不是采集——只删误挂,不新增写法。

## 学校 entity = 学历归属(本部全日制统招)

talent-graph 的学校 entity 回答"该员工是否在 X 校受过本部全日制统招学历教育"。一条已登写法,只有落入下面两类才撤,**其余一律留**。

**该撤一 · 蹭名**:这条 raw 其实是**另一所、声望低于本校的学校**,借了本校的名——这才是要清的污染。典型:独立学院(民办"X大学Y学院",独立招生、分数线低于本部、发自己的毕业证学位证)、附中 / 附小 / 附属实验学校、附属医院、科技园 / 产业园、控股的关联公司或基金会(清华同方 / 紫光)、培训机构 / 短期研修班。判据是"它是不是一个**独立于本校、且更弱**的主体"。

**该撤二 · 本校的非统招轨道**:本校自己办、但走另一套开放 / 非全日制录取的成人学历——继续教育 / 成人 / 自考 / 网络 / 远程教育;双培 / 联合培养(学籍与学位在另一所录取校,本校只教一段)也归此类。本策略只认本部全日制统招,故撤。

**其余一律留。** 尤其下面这些**看着像该撤、其实该留**的,别误伤:

- 校名的字面变形(全称 / 简称 / 英文 / typo / 简繁 / 全半角 / 大小写 / 空格;后面缀了学位或专业也只是变形)
- 本部统招分流的下属研究院 / 学院 / 书院 / 研究生院(深圳研究生院、光华管理学院)、校区、改名 / 曾用名 / 前身
- **联邦制 / 学院制大学的成员校**(PSL 下的高师 ENS、巴黎高等矿业 Mines、巴黎九大 Dauphine):与母体同级的精英组成,是蹭名的反面
- **本校就读、本校发学位的合办项目**(合办 MBA / 双学位):本校发了学位就是本校学历
- **挂牌的精英合作院**(如协和挂"清华大学医学部")、一条 raw 写了两所真实就读校:真实指向本校的部分留

判别核心是"它是不是**更弱的借名者**、或本校的**非统招轨道**"——不是机械套"谁发学位":联邦成员、协和、合办项目都各自发或合发学位,但它们不是更弱的借名者,留。

## 怎么做

批次清单文件里每校已列出 entityId + 当前已登别名;需要时再 `alias list --entity <entityId> --type school` 核对最新状态。绝大多数学校是干净的——通篇都是校名变形和真二级学院,扫一眼就过。只有冒出"该撤一 / 该撤二"形态的可疑写法才深究:用搜索工具核它的招生轨道、办学层次、与本校的强弱关系,确属该撤再 `alias remove --type school --raw-name "<原始名>"`。

**撤一条 = 这条对所有标签永久隐形**,所以默认偏向保留:撤前先确认它确属"更弱的借名者"或"本校非统招轨道";弱证据 / 吃不准 → 留。**宁可漏撤一条,不可错撤一条真归属**——漏撤下次复查还能补,错撤把真学历从下游命中里抹掉了。

搜索工具调用失败 / 限流 → 终止任务,报错退出。不要把"调用失败"当"核不实"跳过——会导致一条没撤但表面成功。

## 完成标准

这一批每校的已登记写法都过一遍;可疑的逐条核实、确认误挂的撤掉。报告复查了多少校、撤了哪些写法(各自归属哪校 + 撤回依据)、哪些可疑但核不实保留了。
