# 复查一批学校实体的已登记别名

你拿到一批学校实体(每校带 entityId + 当前已登记的别名清单,见批次给定的清单文件)。逐校复查这些写法,把误挂的撤掉。这些写法里有一部分是早期用过宽的"挂了校名就归本校"标准登进去的(独立学院、中外合作、双培、继续教育等借名项目被错当成本校),现在按学历教育归属重新核一遍,确属误挂的用 `alias remove` 撤回。这是审查撤回任务,不是采集——只删误挂,不新增写法。

## 项目级约束:学校 entity = 学历教育归属

talent-graph 的学校 entity 服务于员工的学历教育归属——下游回答"该员工是否在 X 学校接受过学历教育"。一条 raw 算不算归属某校,看**它代表的学历是不是经该校本部统招录取、并由该校亲自授予学位**。判据锚定"谁录取、谁发学位",不锚定上课地点 / 挂名 / 历史合作——这三者都能让一个独立主体看起来像本校,但学历不是本校的。

**该留(真归属,别动)**:

- 校名的字面变形(官方全称 / 官方简称 / 英文名 / typo / 简繁 / 全半角 / 大小写 / 空格差异),哪怕后面缀了学位 / 专业(如 "ANU Master of commerce")也只是变形
- 经本校统招录取后院系分流、学位由本校授予的下属研究院 / 学院 / 书院 / 研究生院(深圳研究生院 / 光华管理学院)
- 改名 / 曾用名 / 院系调整前身
- **一条 raw 写了两所真实就读校**(如 "帝国理工学院和伦敦大学学院"、"X大学、Y大学"):其中真实指向本实体的那所要保留,别因"不是单一校名"就撤

**该撤(借了校名,但录取或学位不是本校的)**:

- **独立学院**(民办性质的"X大学Y学院"):独立招生、分数线低于本部、发自己的毕业证学位证(多数已转设更名),是另一所学校
- **中外合作 / 合办项目,且学位由外方独立授予**:不走本校统招、本校也不发学位(如独立设置的中外合作大学)。**反之,本校就读、本校发学位的合办项目(含合办 MBA / 双学位)→ 默认留**——本校发了学位,就是本校学历
- **双培 / 联合培养**:学籍与学位在另一所录取学校,本校只承担一段教学
- **继续教育 / 成人 / 自考 / 网络教育**:另一套开放录取 + 成人学历,非本部全日制统招学位
- 附中 / 附小 / 附属实验学校(基础教育)、附属医院(医疗)、科技园 / 创业园 / 产业园(园区公司)、控股旗下上市公司 / 关联基金会(如"清华同方""清华紫光",控股非办学)、培训机构 / 短期研修班(非学历教育)

## 怎么做

批次清单文件里每校已列出 entityId + 当前已登别名;需要时再 `alias list --entity <entityId> --type school` 核对最新状态。绝大多数学校是干净的——通篇都是校名变形和真二级学院,扫一眼就过。只有冒出上面"该撤"形态的可疑写法值得深究:用搜索工具核实它的招生轨道与学位授予方,确属误挂的才 `alias remove --type school --raw-name "<原始名>"` 撤掉。

撤除是破坏性的,默认偏向保留:核不实 / 吃不准 → 不动。**宁可漏撤一条,不可错撤一条真归属**——漏撤下次复查还能补,错撤把真学历从下游命中里抹掉了。

**别撤成 JOIN-miss**:撤的前提是这条写法要么非学历 / 弱校借强校名(蹭名),要么能改挂到另一个**已存在**的实体。若它本身是受认可的正经高校、库里又没有它的独立实体可改挂,撤掉只会让它对所有标签彻底隐形——这是错撤。典型陷阱:**联邦制 / 学院制大学的成员院校**(如 PSL 下的高师 ENS、巴黎高等矿业 Mines、巴黎九大 Dauphine)与母体同级、是联邦的正经组成,属于蹭名的**反面**——别因"成员校各自授学位"就把它从母体撤掉。判据是为"正确归属院校声望"服务的,不是为机械套"谁发学位"。(对比:**独立学院**是民办弱校借强校名、分数线低于本部、另发证,才是该撤的蹭名。)

搜索工具调用失败 / 限流 → 终止任务,报错退出。不要把"调用失败"当"核不实"跳过——会导致一条没撤但表面成功。

## 完成标准

这一批每校的已登记写法都过一遍;可疑的逐条核实、确认误挂的撤掉。报告复查了多少校、撤了哪些写法(各自归属哪校 + 撤回依据)、哪些可疑但核不实保留了。
