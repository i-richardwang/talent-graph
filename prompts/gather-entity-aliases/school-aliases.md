# 收集一个学校实体的写法

你的任务:对一个目标学校实体,通过 `/gather-entity-aliases` skill 把候选清单里指向它的所有写法登记到 `entity_aliases`。

## 学校 entity = 学历归属(本部全日制统招)

talent-graph 的学校 entity 回答"该员工是否在 target 校受过本部全日制统招学历教育"。一条候选 raw,只有落入下面两类才跳过,其余**确实指向 target** 的写法都登。

**跳过一 · 蹭名**:这条 raw 其实是**另一所、声望低于 target 的学校**,借了 target 的名。典型:独立学院(民办"X大学Y学院",独立招生、分数线低于本部、发自己的毕业证学位证)、附中 / 附小 / 附属实验学校、附属医院、科技园 / 产业园、控股关联公司或基金会(清华同方 / 紫光)、培训机构 / 短期研修班。判据是"它是不是一个**独立于 target、且更弱**的主体"。

**跳过二 · target 的非统招轨道**:target 自己办、但走另一套开放 / 非全日制录取的成人学历——继续教育 / 成人 / 自考 / 网络 / 远程教育;双培 / 联合培养(学籍与学位在另一所录取校,这条归那所录取校)也归此类。本策略只认本部全日制统招。

**其余确实指向 target 的都登**,尤其这些**看着像该跳、其实归 target**的别漏:

- target 校名的各种写法(全称 / 简称 / 英文 / typo / 简繁 / 全半角 / 大小写 / 空格;缀了学位或专业也只是变形)——这本就是采集主体
- 本部统招分流的下属研究院 / 学院 / 书院 / 研究生院(深圳研究生院、光华管理学院)、校区、改名 / 曾用名 / 前身
- **联邦制 / 学院制大学的成员校**(若 target 是这种母体,如 PSL):与母体同级的精英组成,是蹭名的反面
- **target 就读、target 发学位的合办项目**(合办 MBA / 双学位):target 发了学位就是 target 学历
- **挂牌的精英合作院**(如协和挂"清华大学医学部")

判别核心是"它是不是更弱的借名者、或 target 的非统招轨道"——不是机械套"谁发学位":联邦成员、协和、合办项目都各自发或合发学位,但不是更弱的借名者,登。证据不足、核不实指向 target → 按 SKILL 的保守原则跳过(漏采下次能补)。
