# 收集一个学校实体的写法

你的任务:对一个目标学校实体,通过 `/gather-entity-aliases` skill 把候选清单里指向它的所有写法登记到 `entity_aliases`。

## 项目级约束:学校 entity = 学历教育归属

talent-graph 的学校 entity 服务于员工的学历教育归属——下游回答"该员工是否在 X 学校接受过学历教育"。一条 raw 算不算归属 target,看**它代表的学历是不是经 target 本部统招录取、并由 target 亲自授予学位**。判据锚定"谁录取、谁发学位",不锚定上课地点 / 挂名 / 历史合作——这三者都能让一个独立主体看起来像 target,但学历不是 target 的。

**归本校**(同一录取 + 本校学位):

- 下属研究院 / 学院 / 书院 / 研究生院:经本校统招录取后院系分流、学位由本校授予(深圳研究生院 / 光华管理学院)
- 改名 / 曾用名 / 院系调整前身

**跳过——借了 target 的名,但录取或学位不是 target 的**(蹭名,非本校学历):

- **独立学院**(民办性质的"X大学Y学院"):独立招生、分数线低于本部、发自己的毕业证学位证(多数已转设更名),是另一所学校
- **中外合作办学且自主招生**:不走本校统招,学位由外方 / 合作机构授予
- **双培 / 联合培养**:学籍与学位在另一所录取学校,本校只承担一段教学——这条写法归那所录取学校,不归本校
- **继续教育 / 成人 / 自考 / 网络教育**:另一套开放录取 + 成人学历,非本部全日制统招学位

**跳过——明显非本校办学主体**:

- 附中 / 附小 / 附属实验学校(基础教育)、附属医院(医疗)、科技园 / 创业园 / 产业园(园区公司)、控股旗下上市公司 / 关联基金会(如"清华同方""清华紫光",控股非办学)、培训机构 / 短期研修班(非学历教育)
